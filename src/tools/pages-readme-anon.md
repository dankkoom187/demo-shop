# Прототип интернет-магазина защитных плёнок

**[Открыть демо](https://dankkoom187.github.io/demo-shop/)** · исходники в папке [`/src`](./src)

Многостраничный прототип интернет-магазина: каталог, карточка товара, сравнение, гид по выбору,
корзина и оформление заказа, юридические страницы. Логика интерфейса рабочая, бэкенда нет.

> Учебный проект. Товары, цены и контакты вымышлены; оплата, amoCRM и почта не подключены —
> здесь показан интерфейс магазина, а не боевое окружение.

## Что реализовано

| Блок            | Детали                                                                                                                     |
| --------------- | -------------------------------------------------------------------------------------------------------------------------- |
| Вёрстка         | Адаптив от 375 до 2560 px, промежуточные ширины, без горизонтального переполнения                                          |
| Каталог         | Фильтры (тип, толщина, цена), поиск по названию и коду, сортировка по цене, переход из категории                           |
| Карточка товара | Галерея, характеристики, вариант ширины рулона (1,58 / 1,80 м) с разной ценой, количество целыми рулонами, похожие товары  |
| Сравнение       | 8 параметров, группировка по кузову / оптике / стеклу / керамике, до 4 позиций, удаление                                   |
| Корзина         | Количество в рулонах и штуках, сумма позиции, итог, скидка 10% на первый заказ, состояние между страницами                 |
| Оформление      | Физлицо (онлайн-оплата) и юрлицо / ИП (счёт, ИНН), ТК / курьер по СПб / самовывоз, валидация, согласие на обработку данных |
| Состояния       | Пустая корзина, пустое сравнение, «ничего не найдено», ошибки форм, 404                                                    |
| Доступность     | 0 нарушений axe-core на 14 страницах, `main`-лендмарк, подписи полей, контраст по AA                                       |

## Стек

- статический HTML + чистый JavaScript без фреймворка и сборщика — переносится в Tilda или WordPress;
- CSS по дизайн-токенам в `:root`, адаптив на 6 брейкпоинтах;
- сборка страниц из partials (`src/tools/build-pages.js`), данные каталога и статей — `src/data.js`;
- ESLint 9 + Prettier, сценарные тесты и аудит доступности в headless Chrome (puppeteer-core).

## Структура

```
index.html          собранные страницы (их и отдаёт GitHub Pages)
*.html              остальные 13 страниц
styles.css          стили и токены
data.js             каталог и статьи
app.js              общая логика: каталог, корзина, сравнение, drawer
pages.js            логика страниц
media/              скриншоты
src/                исходники: partials, pages, data, pages.js, tools
```

## Локальный запуск

```bash
cd src
npm install
npm run dev      # http://localhost:5173
npm run check    # eslint + prettier + build + тесты + аудит доступности
```

## Проверка

- **14 страниц**: нет горизонтального переполнения на 375 и 1440 px, нет ошибок JS, нет битых
  внутренних ссылок, на месте ключевые элементы;
- **24 сценария**: фильтры и поиск, сортировка, вариант ширины с ценой, корзина и скидка 10%,
  юрлицо и самовывоз, валидация, сравнение по группам, гид и статья, формы;
- **axe-core**: 0 нарушений доступности на всех страницах.
